# 光分千色 · 栅览星河 —— 光栅衍射数字化学习平台

面向师生的光栅衍射学习平台，打通「理论 · 实验 · 前沿应用」的认知闭环。

## 模块

1. 教学微视频 —— 内嵌在线播放
2. 核心知识 —— 光栅衍射原理与关键规律
3. 虚拟仿真实验 —— 单缝衍射 / 多缝干涉 / 光栅衍射
4. 学习路径 —— 前沿导入 → 分层精讲 → 实操验证 → 科技升华
5. 实验测量与分析 —— 分光计测量光栅常数与波长
6. 拓展实验 · 自制光谱仪 —— DVD-R 透射光栅光谱仪

## 本地运行

双击 `index.html` 即可（需保持目录结构完整）。

## 目录结构

- `index.html` 首页
- `css/` 样式表
- `js/` 脚本（星空动画 / 访客统计 / 评论区）
- `sim/` 虚拟仿真实验（单缝 / 多缝 / 光栅衍射）
- `assets/video/video.mp4` 教学视频
