========================================================
 光分千色 · 栅览星河 —— 光栅衍射数字化学习平台
========================================================

【打开方式】
  方法一（推荐）：双击 index.html，用 Chrome / Edge / Firefox
                浏览器打开即可，无需联网。

  方法二：若视频无法播放，可把整个文件夹上传到任意网站空间；
          或在本地用 Python 起一个静态服务器：
             cd 本文件夹
             python -m http.server 8000
          然后浏览器访问 http://localhost:8000

【平台内容】
  1. 教学微视频            —— 内嵌在线播放
  2. 核心知识              —— 光栅衍射原理与关键规律
  3. 虚拟仿真实验          —— 单缝衍射 / 多缝干涉 / 光栅衍射
  4. 学习路径              —— 前沿导入 → 分层精讲 → 实操验证 → 科技升华
  5. 实验测量与分析        —— 分光计测量光栅常数与波长
  6. 拓展实验 · 自制光谱仪  —— DVD-R 光谱仪与谱线验证

【文件夹结构】
  index.html          网站首页（入口）
  css/style.css       样式表
  js/main.js          脚本（星空动画 / 显现动画 / 仿真弹窗）
  assets/video/       教学视频 video.mp4
  sim/                虚拟仿真实验（单缝 / 多缝 / 光栅衍射）

【说明】
  1. 请保持整个文件夹结构完整，勿只拷贝 index.html 单个文件，
     否则视频、图片会无法加载。
  2. 虚拟仿真实验点击卡片即可在弹窗中交互，也可点击
     「进入完整仿真平台」新窗口打开。

【浏览器建议】
  Chrome / Edge / Firefox 最新版。
